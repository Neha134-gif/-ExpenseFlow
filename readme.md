# ExpenseFlow 💰

ExpenseFlow is a simple expense tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add income and expenses
- Edit and delete transactions
- Search and filter transactions
- Sort transactions
- Calculate total income, expenses and balance
- Spending analytics with Pie Chart and Bar Chart
- Save transactions using LocalStorage
- Fetch exchange rate using an API

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage
- REST API
